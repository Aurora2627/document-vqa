# 区域裁剪失败的定性复核

范围：旧 20 文档开发集，冻结原模型九格阅读实验。按保存的逐题配对结果，选择第一条“整页完全匹配、单区域 ANLS 为零”的题进行原图与裁剪复核。属于事后错误分析，不用于估计错误类型在全部数据中的比例，也没有修改本轮实验协议。

## q16444：数字清晰，但行说明被切掉

问题询问吸烟者中希望生活有更多刺激与感受的人所占比例。参考答案是 70 / 70%；整页预测 70，单区域预测 61。

原图大小 2159×1695，模型选中九格区域 6，实际候选框为 `[864, 339, 2159, 1356]`。原图左侧列出各行陈述，中右侧是吸烟者/非吸烟者两列比例。70 与 61 属于相邻的两行。

对原图和保存的第一候选裁剪进行视觉检查：裁剪仍保留列标题以及清晰的 70、61 等数字，但左侧行陈述大部分消失。由此可观察到“数字仍在、用于区分行的上下文被移除”的输入信息损失。它与回答相邻行数值的错误相符；仅凭这一例不能证明模型内部因果机制，也不能把九格的数字概率作为定位真值。

这说明局部放大需要同时保留字段和值的关系。完整宽度横带是一种可检验的替代方案，但是否有效仍需看保存的 OCR 消融，而不是由这张图直接得出结论。整页与原生三图的 processor 路径也不同，融合失败还可能涉及视觉细节和 token 组织，不能全部归因于裁剪位置。

## 同题的新 LoRA 与 OCR 结果

本轮新 LoRA 在这题上，整页预测 70、九格单区域预测 61，与原模型的这一错误模式一致。OCR 全宽横带预测 70，整页加 OCR 也为 70，但仅 OCR 文字预测 64，属于另一列的数值。检索文字中出现了相关陈述及两列的数字；BM25 匹配到相关词并没有自动解决列对应关系。

单例中 OCR 横带保留了正确回答，但整页本来就答对，不能计作对整页的新增收益。20 题汇总中 OCR 裁剪与整页的 EM 同为 12/20，ANLS 风格分数反而下降；图文提示为 8/20。案例用于解释需要保留行列上下文，不证明现有 OCR 策略有效。
